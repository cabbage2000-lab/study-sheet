# 学习任务纸排版审核记录

日期：2026-11-06

## 观察与假设

原样式没有居中纸张标题；题号固定占 6 mm，使用较小字号和独立行高，可能与题干、拼音或多位数编号错位。假设将标题居中、题号栏按字号伸缩并统一题号与首行的行高后，打印版的标题中心误差小于 1 px，题号与首行中心误差小于 1 px，题号列与题干之间至少留 2 px。

## 两轮调整

1. 标题居中，题号栏随字号伸缩；为普通题干与拼音匹配行高，并同步调整文本测量宽度。浏览器断言覆盖 1、10、100、101 题。
2. PDF 页面复审发现抄写题编号与其他题号的右边缘不一致。统一其字号和行高，并增加抄写题及题号列对齐断言。

- `npm run typecheck`：通过；`node --import tsx --test tests/unit.test.ts`：7 项通过。
- `node --import tsx --test tests/browser.test.ts`：5 项通过，覆盖 A4 PDF、答案隔离、多页、公式、语文格子、续页、桌面和手机预览。
- `node --import tsx --test --test-name-pattern 'titles are centered' tests/browser.test.ts`：对齐检查重复执行，覆盖 102 题与跨题型题号列。
- 检查了浏览器截图以及从混合学科 PDF 第一页渲染的图像。生成的 PDF 页数与报告一致。
- 最初受限环境无法启动 Chrome；在获准启动本机浏览器后完成测试。项目标准 npm 测试入口中的 `tsx` IPC 在该环境受限，以上使用 Node 的 `--import tsx` 执行相同测试文件。
