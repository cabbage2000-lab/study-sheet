# 数学错题重做

根据要求选择题型，不能仅看算式长度：

| task | 场景 | 默认书写区 |
|---|---|---|
| oral | 口算、直接写得数 | 至少 12mm（按 8mm 行向上取整） |
| vertical | 列竖式计算 | 48mm 空白区域 |
| steps | 脱式、混合运算 | 56mm 分步计算线 |
| word-problem | 普通应用题 | 64mm 分步计算线，默认单栏 |

`workspaceMm` 可覆盖默认值（10–450mm）。长除法、多步骤题应酌情增加空间。不要预先填好竖式或中间步骤，除非用户明确要求提供框架；目前模板只支持空白竖式区。

## 题目与答案

- 图片转录需区分 `1/l`、`0/6`、小数点、负号、分数线、乘除号。保留题目中的单位、限制及附加问题。
- 普通算式用 `expression`，仅支持数字、加减乘除、括号、整数乘方，接受 × 和 ÷，用 `/` 表示分数。生成器使用 BigInt 有理数做精确计算，不使用浮点近似。
- 混合数要明确改写成 `(整数+分子/分母)`，百分数改写成 `/100`；不得把 `2 1/3` 直接送给计算器。
- 为让分数在纸上纵向排版，同时提供 `prompt`（KaTeX）与语义相同的 `expression`。生成器会校验 expression 的结果，但不能证明任意自然语言 prompt 与 expression 等价，此对应关系必须由模型核对。
- 不支持符号方程求解和证明校验；可以作为普通题面排版，答案由模型/来源核对后提供 `answer`、`answerVerified:true`。不得声称已经由计算器验证。
- `expression` 存在时，用户提供的数值答案必须与计算结果相符，否则拒绝出卷。结果用精确有限小数或最简分数，不自动生成分步解析。
- 非算式题的答案册需要显式 `answerVerified:true`；仅学生卷不要求答案。核对包括单位、数量关系和问法。

例：
```json
{"task":"steps","items":[{"prompt":"\\(\\frac{3}{4} \\div (\\frac{1}{2}+\\frac{1}{4})\\)","expression":"3/4 / (1/2+1/4)","workspaceMm":56}]}
```

不得将无图无法解答的几何题去掉图片后排版；当前渲染器不支持图片题，需先说明并处理完整题意。
