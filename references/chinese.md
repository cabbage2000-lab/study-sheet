# 语文练习

## 看拼音写词语

使用 `task:pinyin`，每题必须有 `word` 和 `pinyin`。题面只展示带声调拼音与空格，答案汉字不会嵌入学生 HTML。`word` 的字数决定格数。

- 拼音按音节以空格分隔：`chūn tiān`。不要使用数字调号代替附调字母。
- 轻声保留无声调，如 `péng you`、`yǎn jing`；`ü` 不能用 `v` 代替。
- 多音字依词义核对：银行 `yín háng`，行走 `xíng zǒu`，音乐 `yīn yuè`，快乐 `kuài lè`。
- “一、不”等字的标调及变调处理遵循用户教材或明确要求，不能把口语变调规则直接当作所有教材的书写标准。
- 音节数校验仅检查数量，不证明发音正确；模型负责核对音节、声调和词语语境。
- 默认田字格 11mm，低年级可用 12mm。长词放不下时减列，不能切掉汉字格。

## 词语抄写

使用 `task:copy` 和 `repeats`（默认 3，范围 1–10）。题面展示范字和空田字格；这是抄写任务，范字不是答案泄漏。不会生成描红字体。

每项 `word` 只包含汉字。词语列表中的逗号、顿号是分隔符，不作为答题格。句子与标点的专门抄写模板不在首版范围内，不要悄悄删除有教学意义的标点。

例：
```json
{"task":"pinyin","items":[{"word":"绿色","pinyin":"lǜ sè"},{"word":"银行","pinyin":"yín háng"}]}
```
